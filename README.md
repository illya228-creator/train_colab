# Fraud Detection

**Локальная система обнаружения потенциально мошеннических банковских транзакций на Python с графическим интерфейсом.**

Fraud Detection — учебный проект по машинному обучению, предназначенный для анализа транзакций с помощью предварительно обученной модели классификации. Приложение загружает данные из CSV, рассчитывает оценки риска, выделяет подозрительные операции и отображает результаты в компактном настольном интерфейсе.

> Проект предназначен для обучения и экспериментирования. Результаты модели требуют проверки и не являются доказательством мошенничества.

## Возможности

- **Локальный анализ данных** — обработка CSV-файла на компьютере пользователя.
- **Машинное обучение** — использование сохранённой модели `scikit-learn`.
- **Автоматическая загрузка** — модель и датасет подключаются из папок проекта.
- **Графический интерфейс** — настольное приложение на PySide6.
- **Статистика транзакций** — общее количество операций, число подозрительных операций и порог классификации.
- **Визуализация риска** — линейный график оценок риска первых 1 000 транзакций.
- **Круговая диаграмма** — соотношение обычных и подозрительных операций.
- **Оценка качества** — отчёт по метрикам классификации, матрица ошибок, PR-AUC, ROC-AUC и сравнение порогов.

Убедись, что необходимые файлы расположены по путям:

Скрипт выводит отчёт классификации, матрицу ошибок, PR-AUC, ROC-AUC и сравнение нескольких порогов.

## Принцип работы

1. **Загрузка:** приложение читает CSV и загружает сохранённую модель.
2. **Подготовка:** из таблицы выбираются признаки, необходимые модели.
3. **Оценка:** `predict_proba()` рассчитывает вероятность положительного класса.
4. **Классификация:** вероятность сравнивается с порогом, сохранённым в артефакте модели.
5. **Сохранение:** пакетный скрипт записывает оценки и результаты классификации в CSV.
6. **Визуализация:** интерфейс отображает статистику, график оценок риска и распределение классов.

В текущей реализации порог классификации по умолчанию составляет `0.50`, если это значение указано в артефакте модели.

## Метрики качества

Для оценки модели используются:

- **Precision** — доля верных обнаружений среди операций, классифицированных как мошеннические.
- **Recall** — доля обнаруженных мошеннических операций среди всех реальных мошеннических операций.
- **F1-score** — гармоническое среднее Precision и Recall.
- **PR-AUC / Average Precision** — качество ранжирования положительного класса с учётом Precision и Recall.
- **ROC-AUC** — способность модели ранжировать положительный класс выше отрицательного.
- **Confusion Matrix** — количество верных и ошибочных классификаций.

### Ограничения оценки

Текущий `evaluate_model.py` проверяет модель на всём исходном датасете. Если модель обучалась на тех же строках, метрики могут быть завышены и не отражать качество на новых транзакциях.

Для корректной оценки следует использовать отдельную тестовую выборку, которая не участвовала в обучении и подборе порога.

## Известные ограничения

- Сохранённая модель ранее выдавала предупреждение о несовпадении версий `scikit-learn` (`1.6.1` и `1.9.1`). Необходимо согласовать версии и при необходимости переобучить модель.
- Порог классификации влияет на баланс между пропущенными мошенническими операциями и ложными срабатываниями.
- Линейный график отображает оценки первых 1 000 транзакций в порядке строк, а не динамику риска во времени.
- Риск модели не является подтверждением мошенничества.
- Проект пока не является промышленной системой банковского мониторинга.
